# Website Srilex Buditra — Desain Gambar No. 3

Website portfolio Full Stack Developer dengan gaya mobile-first dark navy/gold, foto close-up, layanan, portfolio, paket harga, formulir estimasi, WhatsApp, cetak/simpan PDF, alur pemesanan, FAQ, kontak dan footer.

## Cara pakai
1. Buka `index.html` di browser untuk mencoba.
2. Ganti nomor WhatsApp di `script.js` pada `WA_NUMBER` dengan nomor Anda.
3. Upload seluruh isi folder ke repository GitHub Pages `srilexbuditra.github.io`.
4. Pastikan GitHub Pages menggunakan branch `main` dan folder `/ (root)`.

Tidak membutuhkan server lokal agar tetap online setelah dipasang di GitHub Pages.
